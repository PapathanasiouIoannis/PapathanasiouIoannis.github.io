# Scientific figure provenance

The website uses scientific figures only when they document work represented on the page.
The web assets below are raster conversions of complete, unchanged public-release PDFs; no
scientific calculation, cropping, retouching, or data alteration was performed for the site.

| Web asset | Public source artifact | Placement | License and interpretive note |
| --- | --- | --- | --- |
| `src/assets/realized-deformation-geometry.webp` | `figures/realized_deformation_geometry_final_campaign.pdf` in the [BSk24 campaign data v1.0.0 release](https://github.com/PapathanasiouIoannis/EoS-generation/releases/tag/bsk24-campaign-data-v1.0.0) | Homepage and BSk24 case study, stage 1 | Ioannis Papathanasiou, CC BY 4.0. A controlled effective deformation, not a microscopic composition model. |
| `src/assets/thermodynamic-propagation.webp` | `figures/thermodynamic_propagation_final_campaign.pdf` in the same release | BSk24 case study, stage 2 | Ioannis Papathanasiou, CC BY 4.0. Effective one-fluid thermodynamics for accepted cases. |
| `src/assets/representative-stellar-sequences.webp` | `figures/representative_stellar_sequences_final_campaign.pdf` in the same release | BSk24 case study, stage 3 | Ioannis Papathanasiou, CC BY 4.0. Endpoint markers retain their distinct numerical meanings; not every endpoint is a resolved maximum mass. |

The release license is available at <https://creativecommons.org/licenses/by/4.0/>. The other
campaign figures remain discoverable through the release rather than being reproduced here.

Thesis-era figures are deliberately excluded from this iteration. Their provenance and later-audit
interpretation need to be resolved before they can serve as public evidence on the site.
